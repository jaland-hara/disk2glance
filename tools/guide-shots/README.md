# Скриншоты для docs/guide.md

`shoot.sh` переснимает все скриншоты руководства с веб-интерфейса d2g из этого репозитория.
Интерфейс работает на мок-сервере (`mock.py`) с ответами API, записанными на настоящем стенде и
обезличенными: адреса из RFC 5737, вымышленные ID проектов и имена. Поэтому после правки
текстов в `server/d2g/static/` достаточно запустить:

```bash
tools/guide-shots/shoot.sh
```

Нужны macOS и Google Chrome. `shot.js` открывает нужный экран по параметру `?shot=`, данные
этапа переноса выбираются параметром `?scene=` (`01-empty` … `05-finished` в `data/`). Схемы
(`*.svg`) создаёт `docs/img/guide/make-diagrams.py`.
